# H-X
security tool &amp; pen tests

## Antigravity Metasploit Tool

This repository includes the **H-X Antigravity Tool** for pulling and launching Metasploit Framework on your desktop.

### Features

- 🚀 One-command installation of Metasploit to your desktop
- 🎯 Antigravity launcher for easy access
- 📝 Automatic desktop shortcut creation
- 🛡️ Integrated security tool for penetration testing

### Quick Start

1. Clone this repository:
   ```bash
   git clone https://github.com/NOCODECO/H-X.git
   cd H-X
   ```

2. Run the antigravity installer:
   ```bash
   ./antigravity-install.sh
   ```

3. Follow the on-screen instructions to complete setup.

### What It Does

The antigravity installer will:
- Pull the latest Metasploit Framework from GitHub
- Install it to your Desktop (or Home directory)
- Create an antigravity launcher script
- Generate a desktop shortcut for easy access
- Provide setup instructions for dependencies

### Requirements

- Git (for cloning)
- Ruby 3.0.0+ (for running Metasploit)
- Linux or macOS system

### Usage

After installation, you can launch Metasploit using:

```bash
cd ~/Desktop/H-X-Metasploit
./antigravity-launch.sh
```

Or click the desktop shortcut: **H-X Antigravity Metasploit**
